# MuscleLib API – Política de Privacidad

## 1. Recopilación de datos
La API MuscleLib **no recopila, almacena ni procesa datos personales de los usuarios.**

## 2. Cookies
Las cookies se utilizan únicamente para almacenar:
- Preferencia de idioma
- Preferencia de tema (claro / oscuro / automático)

No se utilizan cookies de seguimiento, analítica ni publicidad.

## 3. Compartición de datos
No se comparten datos con terceros.  
Todas las preferencias almacenadas se utilizan exclusivamente para mejorar la experiencia del usuario.

## 4. Cambios en esta política
Esta Política de Privacidad puede actualizarse periódicamente.  
Cualquier cambio se reflejará en esta documentación.
