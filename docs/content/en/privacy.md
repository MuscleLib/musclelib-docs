# MuscleLib API - Privacy Policy

## 1. Scope

This policy describes the current privacy behavior of the MuscleLib documentation website. It does not describe data processing by the MuscleLib API or other services used independently.

## 2. Browser Storage

The website uses browser `localStorage` for two interface preferences:
- `theme`: the selected appearance (`light`, `dark`, or `auto`).
- `activeLink`: the identifier of the active documentation section, used to restore the section on return.

These values remain in your browser, are not cookies, and are not sent with HTTP requests. You can clear them in your browser settings.

## 3. Cookies

The first-party scripts reviewed for this policy do not create or read cookies. External services may use cookies or similar technologies under their own policies; the website does not control those practices.

## 4. External Services

The site loads resources from jsDelivr, cdnjs, Google Fonts, and Vercel Blob, is hosted by Vercel, and may display example images served by the MuscleLib API. When a browser requests these resources, providers may receive technical connection information such as IP address, browser/device details, and the requested resource URL. Each provider handles this information under its own privacy policy and terms. The website code does not establish what providers retain or for how long.

No analytics or advertising integration was identified in the website code reviewed for this policy. This does not make claims about independent practices of external providers.

## 5. Changes

This policy may change when website functionality, storage behavior, or external services change. The current version is published on this documentation website.
